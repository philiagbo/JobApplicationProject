## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> PUT /api/jobs/<id>/description | Untrusted text from the page (and any other site trying a cross-origin request) enters the API |
| paste -> SQLite -> later UI | Stored text is shown by the future UI |
| request thread vs details worker thread | Two writers on the same row |
