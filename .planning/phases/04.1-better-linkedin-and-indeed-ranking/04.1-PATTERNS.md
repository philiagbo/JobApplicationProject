## Pattern Assignments

### `api/core.py` (utility, transform)

**Analog 1: `details_plan`** (L155-164). Change: reorder so excluded-word check comes first, `ok` second, and the never-fetch branch returns `"lookup"` instead of `"skipped"`.
```python
def details_plan(job: dict, settings: dict) -> str:
    if job.get("source") in NEVER_FETCH_SOURCES or never_fetch(job.get("url")):
        return "skipped"          # <- becomes "lookup", moved after the "ok" check
    title = " %s " % normalise(job.get("title") or "")
    if any(normalise(w) and " %s " % normalise(w) in title for w in settings.get("excluded_words", [])):
        return "skipped"
    if len(plain_text(job.get("description") or "")) >= SHORT_DESCRIPTION_CHARS:
        return "ok"
    return "fetch"
```

**Analog 4: label mapping** `_first_label(norm, _TYPES)` L170-177/L191 for Reed job type text.
