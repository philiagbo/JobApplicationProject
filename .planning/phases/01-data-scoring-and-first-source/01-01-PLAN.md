## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/client to Flask /api | Request bodies (settings JSON) are untrusted input |
| Remotive API to app | Job JSON and HTML descriptions come from a third party |
| app to SQLite | Values from both boundaries above are written to disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | api/db.py queries | high | mitigate | Every query binds values as ? parameters; no SQL is built from settings or Remotive values (INSERT OR IGNORE, SELECT ... WHERE status = ?) |
| T-01-02 | Tampering | PUT /api/settings to save_settings | medium | mitigate | Task 2: key allowlist from DEFAULTS, per-type checks, numeric floors, all-or-nothing write, 400 on reject (D-18) |
| T-01-03 | Denial of Service | sources.get_json | medium | mitigate | urlopen timeout=20; failures wrapped in SourceError and returned as 502, so the request never hangs and never crashes the server |
| T-01-04 | Repudiation (site terms) | sources.fetch_remotive | medium | mitigate | Fetch only on explicit POST /api/fetch (D-13); a process-wide lock spaces Remotive calls by REMOTIVE_GAP_SECONDS (31 s); url and source "remotive" stored for the required link-back and attribution; descriptive User-Agent |
| T-01-05 | Information Disclosure | GET /api/settings returns API keys | low | accept | Returned in full by user decision D-17 (local, single user); cross-origin and rebinding reads are blocked by the local-only guard in 01-03 (T-01-10) |
| T-01-06 | Tampering | Remotive HTML stored in jobs.description | low | accept | Phase 1 serves JSON only (application/json) and renders no HTML; the UI pages (UI-01, after this roadmap) must render descriptions as text |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this plan: stdlib urllib replaces the HTTP client, and acceptance checks api/requirements.txt is still exactly "flask>=3.0" |
</threat_model>
