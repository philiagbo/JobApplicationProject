## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| any browser tab to http://localhost:8765/api | Other websites can send requests to localhost or DNS-rebind to it |
| client to job action routes | job_id, action and ?status= are untrusted |
| server errors to client | Exception details must not reach responses |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-08 | Tampering | db.set_status | low | mitigate | Single atomic UPDATE guarded by WHERE status IN (allowed); <int:job_id> and any(...) converters restrict inputs; 404/409 otherwise |
| T-01-09 | Tampering | GET /api/jobs ?status= | low | mitigate | Value checked against db.STATUSES (400 otherwise) and passed as a ? parameter |
| T-01-10 | Information Disclosure / Spoofing | all /api routes (API keys in GET /api/settings, POST /api/fetch) | high | mitigate | before_request local_only: 403 unless the Host hostname is in LOCAL_HOSTS and any Origin hostname is in LOCAL_HOSTS (blocks DNS rebinding and cross-site POST/CSRF) |
| T-01-11 | Information Disclosure | error responses | medium | mitigate | errorhandler(Exception) returns a fixed "Internal server error" message and logs the traceback server-side only |
| T-01-12 | Elevation of Privilege | Werkzeug debugger in the run block | high | mitigate | Debugger only with JOBHELPER_DEBUG=1; server bound to 127.0.0.1 explicitly |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this plan (Flask/Werkzeug already installed, stdlib urllib.parse for urlsplit) |
