api/cv.py (new; the only module that imports the parsing libraries, and it imports only io, pypdf and docx): set MAX_TEXT_CHARS = 200000. read_cv_text(data, kind) follows RESEARCH.md Pattern 10. For kind "pdf", join (page.extract_text() or "") for every page of pypdf.PdfReader(io.BytesIO(data)) with newlines. For kind "docx", join the paragraph texts of docx.Document(io.BytesIO(data)) with newlines (Task 3 adds table cells). Keep the whole read inside one try. Encrypted PDFs raise at extract_text, not at open, so a broad except Exception is right for untrusted bytes; re-raise it as ValueError("Couldn't read text from this CV") chained from the original. Cut the text to MAX_TEXT_CHARS and strip it. Empty text raises the same ValueError, because blank and scanned pages return '' with no exception.

api/app.py (import cv and core):
- MAX_CV_BYTES = 10 * 1024 * 1024, with a ponytail comment: a read cap gives the D-06 specific 400, whereas Flask's request-size config would return 413 for every oversize request, JSON included.
- A helper _profile_json(conn) returns dict(db.get_profile(conn), cv_file=db.cv_file_name()).
- GET /api/profile (profile_get) returns jsonify(_profile_json(get_db())).
- POST /api/profile/cv (profile_cv), in this order:
  1. f = request.files.get("cv"); a missing part or empty filename returns 400 "No file uploaded".
  2. ext = os.path.splitext(f.filename.lower())[1]; anything other than ".pdf" or ".docx" returns 400 "Upload a PDF or DOCX file". kind = ext[1:] ("pdf" or "docx"). The filename is used for nothing else.
  3. data = f.stream.read(MAX_CV_BYTES + 1); more than MAX_CV_BYTES bytes returns 400 "CV is larger than 10 MB".
  4. Magic bytes: data must start with b"%PDF-" for pdf or b"PK\x03\x04" for docx, otherwise 400 "Upload a PDF or DOCX file".
  5. text = cv.read_cv_text(data, kind); a ValueError logs app.logger.warning with the exception class name only (no stack) and returns 400 with str(e).
  6. extracted = core.extract_profile(text).
  7. db.store_cv(data, kind).
  8. db.save_profile(conn, core.merge_profile(db.get_profile(conn), extracted)).
  9. Return jsonify(_profile_json(conn)) with 200.
  Validating and parsing before anything is stored is what keeps a 400 from changing the profile or the file.
